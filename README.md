# claude-mods

Mods til Claude Code.

| Mod | Hvad den gør |
| --- | --- |
| [token-maaler](token-maaler) | Viser hvad projektet, hver opgave og hver dag kostede i tokens og penge, og hvad der kostede mest. |

## Installation

Med Claude Code's plugin-kommandoer (kræver adgang til repoet):

```bash
claude plugin marketplace add Ludomajn/claude-mods
claude plugin install token-maaler@claude-mods
```

Eller manuelt: se [token-maaler/README.md](token-maaler/README.md).
